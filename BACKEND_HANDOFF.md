# PROMIX: фактический контракт существующего API

Актуализировано 22.10.2026 после локальных исправлений. Этот документ не является подтверждением FirstVDS, настройки реальной почты или готовности к публикации. ZIP, GitHub и деплой в этой задаче не выполнялись.

Существующая цепочка сохранена: форма → JSON POST **/api/lead.php** → PHP → PHPMailer → получатель из приватной серверной конфигурации. Само отличие от ранее обсуждавшегося /api/contact не является ошибкой и не требует миграции. Новый Node/Astro API, очередь и база данных не добавлены.

Полный актуальный контракт, реальные имена конфигурации, rate limits, proxy trust, idempotency и таймауты: [backend/README.md](backend/README.md). Это основной технический источник вместо прежних противоречивых рекомендаций данного файла.

Сервер читает backend/config/config.php. Example использует getenv(); корневой .env автоматически не загружается. Фактические имена адресов: LEADS_FROM_EMAIL и LEADS_TO_EMAIL; MAIL_FROM / MAIL_TO не поддерживаются и удалены из example. Получатель не задаётся клиентом. Значения SMTP FirstVDS неизвестны и не выдуманы.

В исходниках добавлено приватное файловое состояние: HMAC-счётчики, fingerprint заявки, ID и статусы, без полных заявок/контактов. Требуется общий для PHP workers локальный каталог вне webroot, случайный секрет и проверенные права. Accepted replay не шлёт письмо повторно; pending/unknown не является успехом. Согласованы frontend ID и серверный additive state. Точные коды и ограничения перечислены в backend/README.md.

Локальная проверка отдельно доказывает: браузер сформировал запрос; реальный PHP его обработал; изолированный SMTP принял синтетическое письмо; проверен товарный контекст и UTM. Это не доказательство попадания письма во входящие simkraski@mail.ru.

Что ещё требуется на реальном сервере: PHP-FPM/Nginx пути и права, приватная конфигурация и сохранность state при рестарте, корректный REMOTE_ADDR/overwrite доверенного proxy, TLS/SMTP-auth, политика лимитов/TTL, таймауты и одна разрешённая владельцем приёмка доставки. Реальная аналитика и почта не использовались для тестов.
