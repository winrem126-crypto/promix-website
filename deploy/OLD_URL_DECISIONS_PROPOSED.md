# Предлагаемые решения для 52 старых URL PROMIX

Составлено 2026-10-23T07:37:04.470Z. **PROPOSED — ни одно из 52 решений не применено к production или действующему примеру редиректов.** Это закрытый поадресный список рекомендаций к утверждению, не повторный аудит.

Итого: **32 × 301, 17 × 410, 3 × 404**. Все 52 адреса из pending представлены ровно один раз. 42 ранее подготовленных 301, 3 сохранённых 200 и отдельный снятый товарный URL латексной остаются в прежней карте. [Машинная версия](OLD_URL_DECISIONS_PROPOSED.json).

Основа: завершённые FINAL_REPORT.md, FINDINGS_STATUS.md, REQUIRED_INPUTS.md, TEST_COVERAGE.md и локальные results/old-new-map.json, legacy-pages.json, legacy-remaining-pages.json, final-full-crawl.json. SHA источников сохранены в JSON. Новых запросов к старому сайту, отправок форм и изменений сервера не выполнялось. Старые 200 — наблюдение QA 22.10.2026, не сегодняшняя production-проверка.

Для 14 новостей и большинства архивов сохранены заголовки/HTTP/SHA, а не полные статьи/состав выборки. Поэтому 410 — предложение окончательного снятия, требующее редакционного решения. Одного отсутствия маршрута в новом проекте недостаточно, чтобы считать 410 уже утверждённым. Похожие заголовки не доказывают дубли: статьи с разными URL остаются отдельными строками.

У всех 301 цель существует и уже прошла финальный QA с 200 на 390/1440. Query category/task поддерживает существующий catalog.js; при выключенном JS откроется общий каталог. Канонический URL фильтрованного каталога остаётся /products/. Это допустимая навигационная замена старой категории, но не новая отдельная SEO-страница. Исходные query-параметры не должны перезаписывать назначенные category/task; UTM можно сохранять только безопасно. Политику query надо проверить при реализации, не конкатенировать второй знак «?».

Для W и его архива предлагается временно 404: сохранённые название/текст противоречат друг другу. Не выбирать между W/FASAD по одному slug, не объявлять 410 без решения о снятии. Для «Декоративных составов» 404 сохраняет честную неопределённость состава. Если компания подтверждает назначения, следующая редакция может заменить эти решения точными 301.

У скрытых acrylic-enamel/polymer-putty до применения 301 нужно подтвердить CAT-01: прямые страницы существуют с 200, но коммерческий статус ещё открыт. Данные грунтовок CAT-02 не изменяются этим документом. Для «Аксессуаров» средняя уверенность: сохранённое меню показывает стеклохолст/флизелин, полного архива нет.

## Порядок применения после согласования

1. Владелец контента/ассортимента утверждает каждую строку или возвращает конкретную цель/перенос контента. При отсутствии решения предлагаемые410 не включать автоматически.
2. Администратор формирует отдельный exact-match snippet только из утверждённых строк; не добавляет wildcard по /news/ или /product_category/ и не перенаправляет неизвестные адреса на главную.
