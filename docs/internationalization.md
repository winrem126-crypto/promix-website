# Языковые версии PROMIX

Сайт содержит русский оригинал и версии `en`, `uz`, `kk`, `tg`, `az`, `ky`, `be`, `hy`, `ka`, `tk`. Языки и подписи хранятся в `src/i18n/config.mjs`. Русские адреса сохранены; остальные используют префикс языка, например `/en/products/`.

## Тексты и обновление переводов

- Исходные русские страницы, product data и технические параметры остаются общими.
- `src/i18n/source-strings.json` — извлечённые уникальные тексты HTML, метаданных, доступных подписей и динамических сообщений.
- `src/i18n/translations/*.json` — подготовленные машинные переводы; в готовом сайте нет обращений к сервису перевода.
- `src/i18n/overrides.json` — отредактированные формулировки интерфейса и названий вариантов. Они имеют приоритет над сгенерированными значениями.
- `src/i18n/runtime-sources.json` — небольшой набор сообщений, нужных JavaScript: формы, ошибки, меню, cookie, поиск. В HTML включаются только эти сообщения, а не весь словарь.

`pnpm build` извлекает актуальные ключи и останавливается при неполном переводе. Для подготовки корпуса без проверки готовности словарей используется переменная `PROMIX_I18N_EXTRACT_ONLY=1`. Скрипт `scripts/prepare-translations.py` позволяет отдельно подготовить недостающие переводы. Генератор обращается к внешнему сервису только при явном запуске; сборка и работа сайта используют сохранённые файлы. Сгенерированный текст следует редактировать в overrides для устойчивого сохранения терминологии.

## Страницы и поведение

Astro регистрирует локализованные маршруты в `src/pages/[locale]/[...page].astro`. После сборки `scripts/i18n/integration.mjs` применяет словари к единому русскому HTML, создаёт локализованные ошибки 404 и обновляет sitemap. Dev-сервер использует ту же обработку через `src/middleware.ts`.

Обработчик переводит текст, метаданные, JSON-LD, aria-подписи и пользовательские data-атрибуты. Идентификаторы товаров, категории, этапы, поля API, числовая геометрия изображений и служебные атрибуты остаются общими. Переводы записываются как текст, не как исполняемая HTML-разметка.

Переключение языка сохраняет страницу, query string и якорь. Все страницы имеют собственный canonical, html lang, Open Graph locale и взаимные hreflang-ссылки. Поиск поддерживает Unicode, локализованные синонимы и русские исходные термины. Согласие cookie общее для языков; контракт отправки заявок сохранён.

Оригинальные PDF, регистрационные номера, фотографии упаковок и логотипы не переводятся и не перерисовываются. На переводных страницах PDF помечены как русские оригиналы. Локальные Inter/Manrope/Noto содержат необходимые дополнительные латинские, кириллические, армянские и грузинские символы.

## Проверка

`pnpm build`, `node --test tests/i18n-projection.test.mjs` и `node --test tests/i18n-browser.test.mjs`. Общая приёмка `tests/site-browser.test.mjs` проверяет русский оригинал; международная приёмка отдельно проверяет страницы, языки, метаданные, навигацию, Unicode-поиск, формы, размеры экрана и переключатель без JavaScript.
