# Буклет PROMIX 2025: наполнение и вопросы

Внутренний файл, не описание товара. Источник — предоставленный `Буклет 2025г-1.pdf`, 28 физических страниц. В подготовленном Markdown он назван `Буклет 2025г-1(2).pdf`. Сведения относятся к изданию 2025 года; актуальность на текущую дату не заявляется. Страницы 3–27 просмотрены как изображения PDF. PDF в `public` не добавлен.

## Без расширения

- `pro-spray-finish` и `pro-spray-improved`: лист 20 имеет заголовок «Базовая финишная», но на изображении явно написано «Улучшенная». В проекте есть обе версии. Требуется привязка листа к SKU.
- `deep-primer`: самостоятельный товар. Его текст на сайте называет состав концентратом, а этикетка — «Грунт глубокого проникновения». Таблица листа 10 перенесена только на явно обозначенный `primer-concentrate`; не распространена на второй продукт.
- `polymer-putty`, `universal-primer`, `latex-paint`, `acrylic-enamel`: отдельного однозначного листа нет.
- Лист 16 H 0,2 «Улучшенная» не получил отдельный SKU. Товар `promix-h-02` имеет обычное название, фракцию 0,2 мм и читаемую этикетку без «Улучшенная»; использован только лист 17. Свойства вариантов не объединены.

Полные исходные записи, решения, SHA-256 PDF, соответствие всех 25 листов и учёт всех 285 исходных разделов сопоставленных товаров находятся в [brochure-2025-review.json](./brochure-2025-review.json). Этот файл не импортируется в сайт.

## Устройство данных

- Каждый новый блок в `src/data/product-brochure-2025.json` содержит имя PDF, физическую страницу и исходный подзаголовок. Таблицы представлены строками и столбцами.
- Шаблоны `{{spec:…}}` читают общие краткие значения из `product.specs`. Форматы рулонов служат одним источником и для каталога, и для таблиц подробной страницы.
- Все 30 публичных объектов товаров, включая slug, названия, изображения, категории, фильтры и краткие параметры, сохранены по значениям. Общие шаблонные поля «Назначение»/«Состояние» не дублируются рядом с полной инструкцией; для концентрата показан запрет нанесения без разбавления.
- Семь несопоставленных страниц используют прежнюю разметку. Первый экран, форма, каталожные карточки, главная, header и footer не перерабатывались.
- Фасовки — сведения об упаковке, без утверждений о наличии. КМ1 стеклохолста указан как заявление буклета; сертификат, ссылка и знак проверки не создавались.
